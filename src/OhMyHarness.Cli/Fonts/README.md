# Bundled CLI fonts

Unmodified regular fonts from the official Google Fonts repository, downloaded 2026-09-24:

- VT323: https://github.com/google/fonts/tree/main/ofl/vt323
- Share Tech Mono: https://github.com/google/fonts/tree/main/ofl/sharetechmono
- Space Mono: https://github.com/google/fonts/tree/main/ofl/spacemono

Each folder contains its original SIL Open Font License (`OFL.txt`). Fonts and licenses are embedded in the CLI and exported together. Windows installation is optional and per-user; other hosts can install the exported TTF with their font manager. The terminal host controls the displayed font.
