# OhMyHarness GUI v1.8.0

The Windows desktop application is now available at the same version as the [CLI v1.8.0](https://github.com/loicdelaunay/OhMyHarness/releases/tag/cli-v1.8.0).

## Download

Download `OhMyHarness-v1.8.0-win-x64.zip`, extract it into a writable folder and launch `OhMyHarness.App.exe`. The archive includes the standalone EXE, MIT license and startup instructions. It contains no database, conversations, credentials or user configuration. Verify the archive with the attached `SHA256SUMS.txt`.

To upgrade, close the application and replace only its executable in your existing portable folder. Keep your database and other data folders. Back up the folder before upgrading; do not open older versions against a migrated database.

## Changes since the previous GUI release

- Response styles in General: DEFAULT, SHORT, PRAGMATIC, DETAILED and FUN, shared with the CLI.
- GitHub update checking and verified download/restart in General, preserving portable data. Updates select the GUI channel and architecture.
- Update, automatic naming and logging settings grouped at the bottom of General.
- Electric dark/light themes, improved theme readability, favorite conversations and optional AI naming.
- Improved queued-message controls, response durations, reading position during streaming and asynchronous nested project-instruction discovery.
- Configurable portable logs and vision-model instructions with component coordinates.
- Full English Markdown documentation and a separate portable CLI sharing the engine and workspace.

See the [changelog](https://github.com/loicdelaunay/OhMyHarness/blob/main/CHANGELOG.md) and [user guide](https://github.com/loicdelaunay/OhMyHarness/blob/main/docs/guide.md).

## Requirements and validation

Windows x64 build using Uno Desktop, with bundled .NET, Python and multilingual embedding resources. The embedded browser requires Edge WebView2. Configure a chat provider; chat models are not bundled. Git, Docker/Podman, OpenCode and MCP integrations retain their own optional prerequisites.

Both Windows standalone publications succeeded. The current update was validated with 163 CLI checks and 38 targeted shared-engine checks covering response styles and the updater. No macOS runtime validation is claimed for this release.
