# OhMyHarness GUI v1.13.0

The **Asset generator** skill gives the AI a layered vector canvas. Watch each drawing update in **Tools > Assets**, inspect colors and layers, capture the artwork for visual feedback, then save it as SVG, PNG, WebP, JPEG or PDF. Drawings are kept with their conversation; the full [asset guide](../asset-generator.md) describes shapes, coordinates, permissions and transparency.

The shared engine also includes the configurable HTTP web research tools introduced in 1.12.0. The matching [CLI v1.13.0 release](https://github.com/loicdelaunay/OhMyHarness/releases/tag/cli-v1.13.0) provides the same asset tools and exports.

Download the archive for Windows x64, macOS Intel/Apple Silicon or Fedora Linux x64. Extract it into a writable folder and launch `OhMyHarness.App.exe` (Windows) or `OhMyHarness.App` (macOS/Linux). The archives include only the executable, MIT license and startup instructions. Keep your existing `database.sqlite` and portable resources when updating. The macOS builds are unsigned and not notarized.

Verify the selected archive against the attached `SHA256SUMS.txt`.
