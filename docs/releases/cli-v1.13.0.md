# OhMyHarness CLI v1.13.0

The optional **Asset generator** skill now lets the AI create layered SVG scenes, refine shapes and colors, inspect a canvas capture and export SVG, PNG, WebP, JPEG or PDF directly from a terminal conversation. The matching [GUI v1.13.0 release](https://github.com/loicdelaunay/OhMyHarness/releases/tag/v1.13.0) adds a live preview with palette and layer controls. See the [asset guide](../asset-generator.md) for the five AI tools and examples.

The CLI also includes the configurable HTTP web research tools from 1.12.0. Download the archive for Windows x64, macOS Intel/Apple Silicon or Fedora Linux x64, extract into a writable folder and run `omh.exe` (Windows) or `./omh` (macOS/Linux). Use `/connect` to select a model provider and `/skills` to enable Asset generator.

The archives include only the executable, MIT license and startup instructions; no conversations or credentials. Keep your existing portable data when updating. The macOS builds are unsigned and not notarized. Verify the archive against the attached `SHA256SUMS.txt`.
